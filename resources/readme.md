# Recursos

## Español

Esta carpeta contiene **material suplementario** que se utiliza como apoyo en varios temas de la asignatura. Estos recursos no pertenecen necesariamente a un único tema, sino que sirven para introducir, practicar o reforzar herramientas y conceptos transversales.

Notebooks disponibles:

- `assert_es.ipynb`: introducción al uso de la instrucción `assert` para comprobar resultados.
- `retos_slicing.ipynb`: explicación y ejercicios prácticos sobre slicing en Python.
- `retos_strings.ipynb`: explicación y ejercicios prácticos sobre cadenas de texto (`str`) y sus principales métodos.

## English

This folder contains **supplementary material** used to support several topics in the course. These resources are not necessarily tied to a single topic; instead, they are intended to introduce, practise, or reinforce cross-cutting tools and concepts.

Available notebooks:

- `assert_en.ipynb`: introduction to using the `assert` statement to check results.
- `slicing_challenges.ipynb`: explanation and practical exercises on slicing in Python.
- `string_challenges.ipynb`: explanation and practical exercises on strings (`str`) and their main methods.

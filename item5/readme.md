# Item 5 - Recursión / Recursion

## Español

Esta carpeta contiene los notebooks del quinto tema de la asignatura. El tema introduce la recursión como técnica de resolución de problemas, trabajando el caso base, el caso recursivo, la traza de llamadas y ejemplos progresivos sobre números, cadenas, listas y búsqueda binaria.

Notebooks disponibles:

- `5_recursion_challenges_es.ipynb`: versión para estudiantes.
- `5_recursion_challenges_solutions_es.ipynb`: versión con soluciones.

## English

This folder contains the notebooks for the fifth topic of the course. The topic introduces recursion as a problem-solving technique, covering the base case, the recursive case, call tracing, and progressive examples with numbers, strings, lists, and binary search.

Available notebooks:

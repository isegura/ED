# Item 2 - Diseño de Algoritmos

## Español

Esta carpeta contiene los notebooks del segundo tema de la asignatura. El tema trabaja el diseño de algoritmos a partir de problemas sencillos, prestando especial atención a la descomposición del problema, el diseño descendente, el uso de funciones y la claridad de las soluciones.

Notebooks disponibles:

- `2_algorithm_design_challenges_es.ipynb`: versión para estudiantes.
- `2_algorithm_design_challenges_soluciones_es.ipynb`: versión con soluciones.

## English

This folder contains the notebooks for the second topic of the course. The topic focuses on algorithm design through simple problems, with special attention to problem decomposition, top-down design, functions, and clear solutions.

Available notebooks:

# Item 1 - Tipos Abstractos de Datos y Modelado Orientado a Objetos / Abstract Data Types and Object-Oriented Modeling

## Español

Esta carpeta contiene los notebooks del primer tema de la asignatura. El tema introduce la necesidad de crear nuevos tipos de datos, el concepto de **Tipo Abstracto de Datos (TAD)**, la diferencia entre TAD y estructura de datos, y el uso de clases y objetos en Python como mecanismo de implementación.

Notebooks disponibles:

- `1_moo_challenges_es.ipynb`: versión para estudiantes.
- `1_moo_challenges_soluciones_es.ipynb`: versión con soluciones.

## English

This folder contains the notebooks for the first topic of the course. The topic introduces the need to define new data types, the concept of an **Abstract Data Type (ADT)**, the difference between an ADT and a data structure, and the use of Python classes and objects as an implementation mechanism.

Available notebooks:

- `1_moo_challenges_en.ipynb`: student version.
- `1_moo_challenges_solutions_en.ipynb`: solution version.

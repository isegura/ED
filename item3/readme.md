# Item 3 - Análisis de Algoritmos / Algorithm Analysis

## Español

Esta carpeta contiene los notebooks del tercer tema de la asignatura. El tema introduce el análisis de algoritmos, la complejidad temporal y espacial, los casos mejor, medio y peor, y la notación Big-O mediante ejemplos progresivos.

Notebooks disponibles:

- `3_algorithm_analysis_challenges_es.ipynb`: versión para estudiantes.
- `3_algorithm_analysis_challenges_soluciones_es.ipynb`: versión con soluciones.
- `Analisis_Empirico_es.ipynb`: notebook complementario sobre análisis empírico.

## English

This folder contains the notebooks for the third topic of the course. The topic introduces algorithm analysis, time and space complexity, best, average, and worst cases, and Big-O notation through progressive examples.

Available notebooks:

- `3_algorithm_analysis_challenges_en.ipynb`: student version.
- `3_algorithm_analysis_challenges_solutions_en.ipynb`: solution version.
- `Empirical_Analysis_en.ipynb`: complementary notebook on empirical analysis.
